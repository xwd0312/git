# Go 从零学习工作台

这个仓库记录我的 Go 语言学习过程，包括语法示例、练习、阶段项目和学习心得。

## 仓库结构

- `main.go`：最小可运行程序。
- `study/`：按主题整理的语法示例与练习。
- `notes/`：学习心得、问题和复盘。
- `projects/`：后续阶段项目（创建项目时再加入）。
- `ROADMAP.md`：从零开始的学习路线与进度。

## 常用命令

```powershell
# 运行入口程序
go run .

# 运行某个独立示例
go run '.\study\1.变量定义.go'

# 格式化模块内的全部 Go 包
go fmt ./...

# 编译并检查全部包
go test ./...
```

## 每次学习的建议流程

1. 在 `study/` 编写一个小而完整的示例。
2. 亲自运行，记录输出以及遇到的错误。
3. 从 `notes/TEMPLATE.md` 复制一份当天心得。
4. 更新 `ROADMAP.md` 中的进度。
5. 检查代码后提交并推送到 GitHub。

## 提交信息示例

```text
study: 学习变量声明与零值
notes: 记录切片学习心得
project: 完成命令行记账程序
fix: 修正并发示例的数据竞争
```
