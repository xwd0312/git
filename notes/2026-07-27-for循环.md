## 我的理解

经典循环：

```go
for i := 0; i <= 100; i++ {
    sum += i
}
```

三部分分别是初始化、继续循环的条件和每轮结束后的操作。

按索引遍历切片：

```go
for i := 0; i < len(list); i++ {
    fmt.Println(i, list[i])
}
```

使用 `range` 遍历：

```go
for index, item := range list {
    fmt.Println(index, item)
}
```

`range` 遍历切片时返回索引和值；遍历 map 时返回键和值。

## 无限循环

```go
for {
    // 重复执行
}
```

省略初始化、条件和递增部分后就是无限循环，通常需要配合 `break`、`return` 或其他退出条件。

## 容易混淆的点

- 循环条件中使用 `i < len(list)`，最后一个有效索引是 `len(list)-1`。
- 不需要索引或值时，可以用空白标识符 `_` 忽略它。
- 遍历 map 的顺序不保证固定，不能依赖它的输出顺序。
- `continue` 跳过当前这一轮，`break` 结束整个循环。
- 示例中的 `sum` 是包级变量；如果多次调用累加逻辑，需要注意旧值是否被保留。
