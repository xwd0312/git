# 2026-07-23：switch 语句

## 今天学了什么

今天学习了 Go 的两种 `switch` 写法：不带表达式的条件 `switch`，以及根据某个值匹配 `case` 的普通 `switch`。

## 运行过的代码

- 示例文件：`study/8.switch语句.go`
- 测试输入：年龄 `10`、星期 `2`
- 运行结果：年龄部分输出“成年”；星期部分的 `case` 代码为空，因此没有额外输出。

## 我的理解

不带表达式的写法：

```go
switch {
case age <= 0:
case age <= 18:
default:
}
```

它相当于依次判断每个条件，执行第一个为 `true` 的分支。

带表达式的写法：

```go
switch week {
case 1:
case 2:
default:
}
```

它会把 `week` 与各个 `case` 的值进行比较。

## fallthrough

Go 的 `case` 默认执行完就结束，不需要手动写 `break`。`fallthrough` 的作用不是跳出 `switch`，而是强制继续执行紧邻的下一个 `case` 代码块，并且不会再次判断下一个 `case` 的条件。

在当前示例中，如果 `age <= 0`，程序会先输出“未成年”，然后因为 `fallthrough` 继续执行下一个分支并输出“成年”。这适合观察语法，但实际年龄分类通常不需要这样处理。

## 容易混淆的点

- Go 的 `switch` 默认不会自动贯穿到下一个 `case`。
- `fallthrough` 会无条件进入下一个分支，使用前要明确是否真的需要。
- `default` 在所有 `case` 都不匹配时执行。
- `case` 中没有语句时，即使匹配也不会产生输出。
