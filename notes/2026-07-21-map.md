# 2026-07-21：map

## 今天学了什么

今天学习了 Go 的 `map`：使用字面量和 `make` 创建 map、按键读取值、用 `value, ok` 判断键是否存在，以及用 `delete` 删除键。

## 运行过的代码

- 示例文件：`study/6.map.go`
- 使用命令：`go run '.\study\6.map.go'`
- 运行结果：程序正常结束，键 `4` 对应空字符串，但查询结果中的 `ok` 仍然是 `true`。

## 我的理解

- `map[int]string` 表示键是 `int`、值是 `string` 的映射。
- map 字面量可以在创建时直接写入键值对。
- `make(map[int]string)` 创建一个可以写入的空 map。
- 读取不存在的键不会报错，而是返回值类型的零值。
- `value, ok := userMap[key]` 中，`value` 是查询结果，`ok` 表示键是否存在。
- `delete(userMap, key)` 删除指定键；键不存在时调用 `delete` 也不会报错。

## nil map 与初始化

```go
var userMap map[int]string
```

这是 nil map。它可以读取、遍历和删除，但不能直接写入新键，否则运行时会报错。需要先用 `make` 或 map 字面量初始化：

```go
userMap := make(map[int]string)
userMap[1] = "xwd"
```

因此准确的说法是：map 在写入键值对之前需要初始化，而不是所有操作之前都必须初始化。

## 容易混淆的点

- 键不存在和键存在但值是零值，是两种不同情况，需要通过 `ok` 区分。
- 示例中的键 `4` 确实存在，只是它的值为 `""`，所以 `ok == true`。
- map 是引用类型；把 map 赋给另一个变量时，两者通常操作同一份底层数据。
- 遍历 map 时，键的出现顺序不保证固定。
