# 2026-07-18：基本数据类型

## 今天学了什么

今天学习了 Go 的部分基本数据类型，包括无符号整数、`byte`、`rune`、字符串和布尔值；还练习了字符输出、转义字符、反引号原始字符串以及不同类型的零值。

## 运行过的代码

- 示例文件：`study/3.基本数据类型.go`
- 使用命令：`go run '.\study\3.基本数据类型.go'`
- 运行结果：程序正常结束，整数、字符、字符串和零值都符合预期。

## 我的理解

- `uint8` 是 8 位无符号整数，取值范围是 `0` 到 `255`。无符号表示没有负数，但可以保存 `0`。
- `byte` 是 `uint8` 的别名，常用于表示一个字节。
- `rune` 是 `int32` 的别名，常用于表示一个 Unicode 码点，适合表示中文等字符。
- 单引号表示字符，例如 `'a'` 和 `'徐'`；双引号表示字符串，例如 `"你好"`。
- `%c` 按字符显示数值，`%d` 按十进制整数显示数值。因此 `'a'` 可以显示为字符 `a`，也可以显示为数值 `97`。
- 反引号可以定义原始字符串，其中的换行会被保留下来。
- Go 的 `bool` 是独立的布尔类型，不能把整数直接转换为布尔值，也不能参与普通数值运算。

## 实际运行结果

- `uint8(255)` 输出 `255`。
- `'a'` 的数值是 `97`。
- `'徐'` 的 Unicode 码点是 `24464`。
- `\t` 会产生制表符。
- `\"` 可以在双引号字符串中表示一个双引号，`\\` 表示一个反斜杠。
- `int`、`string`、`bool` 的零值分别是 `0`、`""`、`false`。因为字符串零值不可见，最终输出看起来像 `0  false`，中间的空白位置就是空字符串。

## 容易混淆的点

- `uint8` 不只是能存正整数，它的范围包含 `0`。
- `byte` 表示一个字节，不一定能单独保存一个完整的中文字符。
- `rune` 表示 Unicode 码点，但字符串本身是一串字节。
- 单引号与双引号含义不同：单引号是字符，双引号是字符串。
- 普通字符串会处理转义字符；反引号原始字符串会尽量保留原始内容。
