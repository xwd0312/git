# 2026-07-17：输入与输出

## 今天学了什么

今天学习了 Go 标准库 `fmt` 包的基本输入输出功能，包括普通输出、自动换行、格式化输出、把格式化结果保存到字符串，以及从终端读取用户输入。

## 运行过的代码

- 示例文件：`study/2.输入输出.go`
- 使用命令：`go run '.\study\2.输入输出.go'`
- 运行结果：示例能够输出文本、数字、类型和格式化后的浮点数，也能读取终端输入。

## 我的理解

- `fmt.Print`：直接输出，末尾不会自动换行。
- `fmt.Println`：输出后自动换行，多个参数之间会加入空格。
- `fmt.Printf`：按照格式字符串输出，例如 `%s`、`%d` 和 `%.2f`。
- `%T`：显示值的类型。
- `%v`：按默认形式显示值；`%#v` 会显示更完整的 Go 语法形式，例如空字符串显示为 `""`。
- `fmt.Sprintf`：返回格式化后的字符串，不直接输出到终端。
- `fmt.Scan(&name)`：读取输入，并通过变量地址把内容写入 `name`。
- `n, err := fmt.Scan(...)`：`n` 是成功读取的值数量，`err` 是读取错误。

## 运行时观察

- `Print` 和没有 `\n` 的 `Printf` 会让相邻内容连在同一行。
- `%.2f` 会把 `3.1415` 格式化为 `3.14`。
- 示例连续调用了两次 `fmt.Scan(&name)`，所以程序会等待两次输入，第二次输入会覆盖第一次输入。
- `var name string` 未赋值时也有零值，字符串的零值是空字符串 `""`。

## 容易忘记的点

- `fmt` 是包，`Println`、`Printf`、`Scan` 等才是函数。
- `Printf` 不会自动换行，需要时应在格式字符串末尾加入 `\n`。
- `Scan` 要修改变量，因此传入的是 `&name`，而不是 `name`。
- `err == nil` 表示没有发生错误，打印时显示为 `<nil>`。
