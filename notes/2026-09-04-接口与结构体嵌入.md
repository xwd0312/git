# 2026-09-04：接口与结构体嵌入

## 今天学了什么

今天学习了接口的隐式实现、接口参数、类型断言、`any`，以及通过结构体嵌入复用字段和方法。

## 运行过的代码

- 示例文件：`study/函数/11.接口.go`
- 运行结果：`Chicken` 和 `Cat` 都能传入 `sing` 函数，并根据各自的具体类型调用方法。

## 我的理解

```go
type Sing interface {
    sing()
    getName() string
}
```

- 一个类型只要拥有接口要求的全部方法，就自动实现该接口，不需要显式声明。
- `sing(c Sing)` 可以接收任何实现了 `Sing` 的类型。
- 接口规定“必须具备什么能力”，具体方法内容由 `Chicken`、`Cat` 等类型实现。
- `any` 是 `interface{}` 的别名，可以保存任意类型的值。

## 结构体嵌入

```go
type Cat struct {
    Chicken
}
```

- 这是结构体嵌入，不是传统面向对象中的继承。
- `Chicken` 的字段和方法可以提升到 `Cat`，因此可以使用 `cat.Name`。
- 如果 `Cat` 自己定义了同名方法，会优先调用 `Cat` 自己的方法。
- 初始化嵌入字段时可以写成 `Cat{Chicken: Chicken{Name: "咪咪"}}`。

## 类型断言

```go
switch service := c.(type) {
case Chicken:
    fmt.Println(service)
}
```

- 类型 switch 检查接口内部保存的具体动态类型。
- `Chicken` 与 `Cat` 仍然是不同类型；`Cat` 嵌入 `Chicken` 不代表 `Cat` 就是 `Chicken`。
- 因此 `case Chicken` 只匹配实际类型为 `Chicken` 的值，不匹配 `Cat`。

## 容易混淆的点

- 接口只声明方法要求，不提供这些方法的具体实现。
- 变量名叫 `cat` 不代表它的类型是 `Cat`，要看右侧实际创建的类型。
- `fmt.Println` 适合打印接口值；内置 `println` 打印接口时可能显示底层地址。
