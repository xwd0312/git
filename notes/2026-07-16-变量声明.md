# 2026-07-16：变量声明

## 今天学了什么

今天建立了第一个 Go 程序，并开始学习变量声明。Go 可以先声明变量再赋值，也可以在声明时赋值；当编译器能推断类型时，可以省略显式类型。在函数内部，还能使用 `:=` 完成短变量声明。

## 运行过的代码

- 入口程序：`main.go`
- 变量示例：`study/1.变量定义.go`
- 计划使用的命令：`go run .`、`go run '.\study\1.变量定义.go'`
- 环境状态：当前终端尚不能识别 `go` 命令，安装 Go 或配置 PATH 后再补充运行结果。

## 我的理解

- `var name string`：先声明一个字符串变量，再单独赋值。
- `var name1 string = "xwd"`：声明时明确写出类型并赋值。
- `var a1, a2 = 1, 2`：一次声明多个变量，并由编译器推断类型。
- `name2 := "XWD"`：函数内部最简洁的声明方式。
- 包级变量要使用 `var`，不能在函数外使用 `:=`。


## 容易忘记的点

- `:=` 只能在函数内部使用。
- 声明了局部变量却不使用时，Go 编译器会报错。
- 代码能看懂不等于已经掌握，需要亲自修改和运行示例。
