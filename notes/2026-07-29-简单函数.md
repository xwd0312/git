- 测试输入：`1`
- 运行结果：输出 `hello`、`XWD`、可变参数之和 `15`，最后调用 `login()` 输出 `login`。

## 我的理解

- `func sayHello()` 声明一个没有参数和返回值的函数。
- 函数内部可以定义匿名函数，并把它赋给变量，例如 `getName`。
- `func() string` 中的 `string` 表示函数会返回一个字符串。
- `numbers ...int` 是可变参数，可以接收任意数量的整数；函数内部把它当作 `[]int` 使用。
- 一个函数可以返回多个值，例如 `(string, bool)`。
- 返回值可以命名，例如 `(val string, ok bool)`；没有主动赋值的 `bool` 返回值保持零值 `false`。

## 输出与返回值的区别

- `fmt.Println(value)` 是产生终端输出的操作。
- `return value` 是把结果交给函数调用者，本身不会自动打印。
- 没有返回值的函数只能直接调用，不能把调用结果放进 `fmt.Println`。
- 有返回值的函数可以写成 `fmt.Println(getName())`。

## 可变参数求和

```go
func sum(numbers ...int) {
    var total int
    for _, n := range numbers {
        total += n
    }
    fmt.Println(total)
}
```

这里的 `_` 表示忽略切片索引，只使用每个整数值。调用 `sum(1, 2, 3, 4, 5)` 得到 `15`。

## 容易混淆的点

- 函数的参数类型写在参数名后面。
- `return` 后的数据数量和类型必须与函数声明一致。
- 命名返回值也有零值；如果忘记赋值，函数仍可能返回零值。
- 当前 `r1` 和 `r2` 只完成了定义，没有在 `main` 中调用，所以运行时看不到它们的结果。
- 函数内部打印和函数返回结果是两种不同的设计方式。
