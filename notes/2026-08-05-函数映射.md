# 2026-08-05：函数作为值

## 今天学了什么

今天在简单函数的基础上，学习了函数也可以作为值保存到 `map` 中，再根据用户输入选择并调用对应函数。

## 运行过的代码

- 示例文件：`study/函数/10.简单函数.go`
- 测试输入：`1`
- 运行结果：先执行登录逻辑，随后从 map 中取出并调用 `sayHello`。

## 我的理解

```go
var userMap = map[int]func(){
    1: sayHello,
}
```

- `map[int]func()` 表示键是整数，值是“无参数、无返回值的函数”。
- `sayHello` 表示函数本身；`sayHello()` 才表示立即调用函数。
- `fun, ok := userMap[num]` 中，`fun` 是查询到的函数，`ok` 表示键是否存在。
- 只有 `ok == true` 时才应调用 `fun()`，否则 `fun` 是 nil，调用会引发 panic。

## 容易混淆的点

- 变量名 `fun` 不决定类型，map 的值类型 `func()` 才决定它保存的是函数。
- 函数签名必须匹配；带参数或返回值的函数不能直接放入 `map[int]func()`。
- 函数 map 适合实现菜单分发，可以减少较长的 `switch`。
