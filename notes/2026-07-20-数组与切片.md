## 数组

- `[3]string` 表示长度固定为 `3` 的字符串数组，长度也是数组类型的一部分。
- Go 不支持负数索引，因此不能用 `array[-1]` 获取最后一个元素。
- 最后一个元素的索引是 `len(array)-1`。
- 数组的长度固定，创建后不能通过 `append` 增加元素。

示例中的数组：

```go
var nameList [3]string = [3]string{"xwd", "张三", "李四"}
```

运行时输出最后一个元素为 `李四`。

## 切片

- `[]string` 表示字符串切片，方括号中没有固定长度。
- `var list []string` 得到 nil 切片，但仍然可以安全地配合 `append` 使用。
- `[]string{}` 和 `make([]string, 0)` 会得到长度为 `0` 的非 nil 空切片。
- `make([]int, 3)` 创建长度为 `3` 的整数切片，其中的元素使用整数零值，所以输出 `[0 0 0]`。
- 长度为 `0` 的切片不能直接访问索引 `0`，需要使用 `append` 添加元素，或者创建时指定需要的长度。

## 从数组获取切片

```go
array := [3]int{1, 2, 3}
slices := array[:]
```

`array[:]` 表示从数组开始位置一直取到结束，结果是 `[1 2 3]`。这个切片引用数组的底层数据，并不是完全独立的新数组。

切片区间遵循左闭右开规则：

```go
array[0:2]
```

包含索引 `0` 和 `1`，不包含索引 `2`，因此结果是 `[1 2]`。

## 排序

- `sort.Ints(ints)` 是整数切片升序排列的快捷写法。
- `sort.IntSlice(ints)` 让整数切片满足通用排序接口。
- `sort.Reverse(...)` 把原来的升序比较规则反转为降序规则。
- `sort.Sort(...)` 根据提供的比较规则执行排序。
- 排序操作会直接修改原切片，而不是返回一个新的已排序切片。

降序的完整写法是：

```go
sort.Sort(sort.Reverse(sort.IntSlice(ints)))
```

当前示例执行了降序排序，但排序后没有再次输出 `ints`，所以运行结果中只能看到前面的升序结果。

## 数组与切片的核心区别

| 对比项 | 数组 | 切片 |
| --- | --- | --- |
| 长度 | 固定 | 可以通过 `append` 增长 |
| 类型写法 | `[3]int` | `[]int` |
| 零值 | 固定长度的零值元素 | `nil` |
| 常见用途 | 元素数量固定的数据 | 日常使用的动态序列 |

## 容易混淆的点

- `:=` 只负责声明变量和推断类型，`[]string{}` 才是创建非 nil 空切片的表达式。
- nil 切片可以使用 `append`，不必为了添加元素而提前实例化。
- `make([]int, 3)` 中的 `3` 是长度，不只是预留空间。
- 切片区间的结束索引不包含在结果中。
- 数组和切片的类型不同，但可以通过 `array[:]` 从数组得到切片。
