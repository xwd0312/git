# 2026-07-29：if 条件判断

## 今天学了什么

今天使用多个 `if` 判断年龄区间，并通过提前 `return` 结束函数，避免继续执行后面的条件。

## 运行过的代码

- 示例文件：`study/7.if语句.go`
- 测试输入：`20`
- 运行结果：输出“青年”。

## 我的理解

- Go 的 `if` 条件不需要写圆括号，但代码块必须使用大括号。
- 条件结果必须是 `bool`，不能用整数代替真假值。
- `return` 会直接结束当前函数，因此后面的判断不会继续执行。
- 当前代码按从小到大的年龄上限依次判断，可以避免区间重叠。

执行过程以年龄 `20` 为例：

- `age <= 0` 为 `false`。
- `age <= 18` 为 `false`。
- `age <= 35` 为 `true`，输出“青年”并结束函数。

## 提前返回

这种写法称为提前返回：

```go
if condition {
    // 处理当前情况
    return
}
```

它可以减少很多层 `else` 嵌套，让代码从上到下更容易阅读。

## 容易混淆的点

- `return` 结束的是当前函数，不只是当前 `if`。
- 如果 `fmt.Scan(&age)` 读取失败，`age` 会保持零值；以后学习错误处理时应检查返回的 `err`。
- `break` 和 `continue` 主要用于循环或 `switch`，不能代替这里的函数 `return`。
